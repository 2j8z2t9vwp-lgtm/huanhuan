# 全功能桌面安装包：制作者说明

## 当前状态

已准备原生桌面入口、原有前后端、完整打包脚本和 macOS 云构建工作流。尚未在 macOS 执行构建，当前 ZIP 是源码交接包，不是已完成的 DMG。只有 macOS 构建与包内自检成功才会生成 DMG。

接收者最终只需要把应用拖进“应用程序”、双击启动、首次填写 API Key。她不需要安装 Homebrew、Python、Node 或输入命令。此文档的后续操作供制作者使用。

## 保留的功能

同一份 static 前端与 app 后端，不删减页面和接口：链接解析、视频上传与播放、关键帧提取、本地中文转写、AI 深度拆解、参考骨架迁移、原创/剧情/Vlog 等切入点、脚本编辑与导出、拍摄日历、发布复盘、竞品观察、宣传项目、四个开源集成、AI 设置、Cookie 导入、备份和清理。

内置 Python 依赖、FFmpeg / ffprobe、Node.js、Playwright Chromium、默认 base 语音模型、完整开源集成及骨架迁移 Skill。选择其他语音模型仍会首次下载。云 API 和平台限制与原工作台相同，不能承诺所有抖音链接成功。

应用数据写入 `~/Library/Application Support/欢欢工作台`，不写入只读应用包。更新应用不会覆盖该目录。密钥使用 Mac 钥匙串。关闭主窗口会停止此进程的后端及宣传项目预览。

## 在 Mac 构建一次

解压完整源码包，安装 Homebrew，然后双击「制作Mac安装包.command」。耗时与体积取决于依赖，包含浏览器及语音模型，最终安装包会明显大于源码 ZIP。运行过程中不要关闭终端。

产物在 dist 中，Apple 芯片是 arm64，Intel 是 x86_64；使用与女朋友电脑对应的版本。

## 云端构建

将不含 data、.venv、tools、node_modules 的完整源码上传到自己有权限的 GitHub 仓库，保留 `.github/workflows/build-mac.yml`。在 Actions 中手动执行 “Build full Mac desktop workbench”。它会分别构建两个架构，完成包内视频抽帧、工具启动、MCP 握手、内置浏览器启动等检查，成功后保存 DMG 为运行附件。不会自动发布 Release。私有仓库 Actions 可能消耗额度，请自行查看账户计费。

## 交付验收

构建脚本自动验证的范围不等于全功能人工验收。在没有安装 Python、Node、FFmpeg 的 Mac 用户账号上，从 DMG 拖入应用后验证：启动和退出；真实上传与播放；转写；填入自己的 API 后拆解与生成；脚本编辑与导出；日历；复盘；竞品保存；宣传项目；Cookie 导入；清理预览；重新打开数据仍在。AI 计费测试需由使用者明确发起。

WKWebView 与浏览器的下载行为不同，CSV/JSON/Markdown 导出需在实际 Mac 窗口中确认。包内自动测试无法代替这项操作。

## 签名与公证

此构建默认仅由打包工具作本地签名，不包含 Developer ID 签名及 Apple 公证。系统可能拦截首次打开；不要把这个状态描述成无需任何提示即可启动。若需要标准的顺畅安装体验，制作者还需要 Apple Developer ID 证书及公证流程。不得把证书私钥或 API Key 提交到仓库。
